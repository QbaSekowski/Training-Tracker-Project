# Training Tracker project

## Requirements

**Business need:**

An organization wants to provide an opportunity for all employees to participate in training sessions and courses. The organization

wants to create an application that will provide an opportunity for everyone to apply for the training and provide details of the training sessions.

Line Managers should have ability to approve or reject requests from employees after submission.

Stakeholders should have ability to view analytics for all submitted applications.

**Key features of the solution:**

- User should be able to view all their applications
- User should be able to fill in the participation form
- Store all requests in the database - SharePoint List
- User should be able to automatically receive a confirmation email when an application is submitted
- Notify the line manager of the employee when the application is sent
- The ability to filter applications by various options
- Have a branded design (Innowise logo attached)
- Have a user-friendly interface
- Be able to visualize data and analyze it in real time
